## 💾 TECHNICAL: How Persistence Works

### **LocalStorage Keys**

```javascript
// Meal Plans (temporary planning area)
'meal-plan-tracked-foods' → Your tracked foods
├── Persists when switching tabs
├── Persists when refreshing page
└── Clears when clicking "Add to Today's Meals"

// Dashboard (permanent daily log)
'food-entries' → Today's actual meals
├── Persists across sessions
├── Accumulates throughout day
└── Separate from Meal Plans tracker
```

---

### **What Gets Saved**

**When you track a food in Meal Plans:**
```javascript
localStorage.setItem('meal-plan-tracked-foods', [
  {
    id: "chicken-123",
    food: { name: "Chicken Breast", calories: 165... },
    grams: 150,
    nutrients: { calories: 248, protein: 46.5... }
  }
])
```

**When you click "Add to Today's Meals":**
```javascript
// 1. Get Meal Plans foods
const trackedFoods = JSON.parse(
  localStorage.getItem('meal-plan-tracked-foods')
)

// 2. Transfer to Dashboard
const dashboardMeals = JSON.parse(
  localStorage.getItem('food-entries')
)

// 3. Combine
const allMeals = [...dashboardMeals, ...trackedFoods]

// 4. Save
localStorage.setItem('food-entries', allMeals)

// 5. Clear Meal Plans tracker
localStorage.setItem('meal-plan-tracked-foods', [])
```
